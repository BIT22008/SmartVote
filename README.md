# SmartVote
SmartVote is a secure online voting system for organizations that enables transparent and tamper-resistant elections. It uses multi-factor authentication, ensures voter privacy, enforces one-voter-one-vote, and supports multiple elections with secure candidate management.

#Prototype Description::
This project is currently in the High-Fidelity Prototype stage. It serves as a comprehensive Proof of Concept (PoC) for a secure, transparent, and decentralized voting ecosystem.

#Purpose of the Prototype::
The primary goal of this prototype is to demonstrate the User Experience (UX) and the Authentication Workflow of a biometric-integrated voting platform. It visualizes how an administrator interacts with election data and how voters are verified using non-traditional methods (CNIC & OTP).

#Current Prototype Scope::
Front-End Architecture: A fully responsive UI built with Bootstrap 5, showcasing all critical administrative modules.
Authentication Flow: Simulated logic for CNIC input, Email OTP (One-Time Password) generation, and Biometric verification steps.
Data Visualization: Dynamic rendering of election results using Chart.js to demonstrate real-time data tracking.
State Management: Client-side JavaScript handles section switching (SPA-style) to mimic a seamless application experience.
